A complete maintenance loop

From first install to fast recovery.

Each command does one job, reports what changed, and keeps destructive work explicit.

01

Install

millennium install

Set up the CLI and choose how Millennium updates.

02

Diagnose

millennium diag

Inspect Steam, the hook, channels, and scheduled jobs.

03

Repair

millennium doctor

Apply targeted fixes with confirmation and dry-run support.

04

Maintain

millennium upgrade

Update safely, roll back when needed, and manage themes.
