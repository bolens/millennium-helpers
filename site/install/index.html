Install Millennium Helpers

Close Steam first. Choose your operating system, copy the command, and run it in a terminal.

Linux

curl -fsSL https://raw.githubusercontent.com/bolens/millennium-helpers/main/install.sh | bash -s -- install

macOS

brew tap bolens/tap
brew install millennium-helpers

Windows

winget install bolens.millenniumhelpers

Scoop is also supported from the project manifest.

Check the installation

millennium --version
millennium diag

The diagnostic command reads your setup and does not change files.
