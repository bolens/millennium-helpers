Everyday guide

Keep Millennium working

Start with a health check. Close Steam before a repair, update, or rollback.

Check your setup

millennium diag

This is safe to run first because it only reads your setup.

Repair a reported problem

millennium doctor

Review every proposed change before confirming it.

Update Millennium

millennium upgrade

Enable daily updates

millennium schedule enable stable

Choose a theme

millennium theme list
millennium config theme NAME

Manage plugins

millennium config plugins
